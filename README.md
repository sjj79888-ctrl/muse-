# muse的衣柜

小满 QQ 表情图的定稿库 + 生成方法。新账号拿到这个仓库，按下面方法接着画，不用再问。

## 这是什么

- 每个文件夹是一种情绪（表情分类），里面是 Torres 通过的定稿图。
- 旧图全部作废，只有这里的图能用（2026-11-07 他亲口说的：之前的所有图片都不要了）。
- 通过的图先本地收着，等他发话再一次性批量上传服务器，不要擅自上传。

## 关于图片存放

仓库里的图片是 base64 文本（`.b64` 后缀），因为 GitHub 连接器只能推文本、推不了图片二进制。文件名和图名一致，只是后缀是 `.b64`。要看图先解码：

```bash
base64 -d 抱抱/01-公园张开双臂.b64 > 01-公园张开双臂.webp
```

以后如果直接传了 `.webp` 进来，对应的 `.b64` 可以删掉。

## 模板

- `template/avatar.webp`：Muse 现在的虚拟形象（蓝长发、黑裙、鲸尾）。
- 生成时永远以这张图为模板。

## 画风（硬规矩，违反必返工）

- 柔和细腻、写实感强的动漫插画风；正常身体比例，不要 Q 版。
- 表情图里不要鲸尾（头像本身有尾巴，图里不要）。
- 耳朵要是正常人耳，不要鲨鱼鳍耳、不要尖耳、不要变形耳。
- 发色可以随衣服、场景自由搭配。
- 同一套里的画风必须一致：后画的拿同套第一张当画风参考（委屈第 4 张就是这么对齐的）。
- 丝袜要包到脚趾，脚趾不能露在袜子外面。

## 生成流程

1. 他说要什么情绪（比如“生成三张委屈的”），先按头像模板画一套：默认 3 张，每张衣服、场景、动作都不一样；他给几套衣服就画几张。
2. 他会发衣服照片（镜像自拍截图），按他发的顺序换上重画：第 1 套 → 第 1 张，第 2 套 → 第 2 张……
3. 画完先自己读一遍核对：衣服对不对、有没有尾巴、耳朵正不正常、画风一不一致，再发给他看。
4. 他提修改，只改他点的那一处，别自作主张改别的。
   - 教训（生气第 3 张）：他说“第三张太夸张了”，指的是地面碎石太夸张，他要的是原图只清碎石、表情动作全不动。我却把整张改温和了，还连改了三版，全错。记住：他说什么就改什么。
   - “不够生气” = 表情往生气了改，但地面、动作这些该有的不用变。
5. 他说“可以 / OK 了”才算通过。通过的图按分类收进这个仓库。
6. 上传服务器是另一件事：等他发话一次性批量上传；上传只重建 bridge，不动 napcat（会掉 QQ 登录），不动 .env。

## 情绪分类（画图时要知道，桥里就是这么触发的）

- 表情由小满回复的情绪决定，不是他那句话的情绪。
- “看看腿”是例外，只认他消息里的这三个字，且只有他本人（QQ 1323841589）能触发。
- “趴着”也是例外，只认他消息里的这三个字，且只有他本人（QQ 1323841589）能触发，发单张跪姿图。
- 委屈不认“笑哭”，开心不认“不同意”，睡觉不认“困难”。
